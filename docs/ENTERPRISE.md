# AI碳核算与减排管理系统企业能力

## 领域覆盖

- **组织与运营边界**：管理法人、设施、控制权和盘查范围
- **活动数据**：采集能源、燃料、冷媒、物流、采购和差旅数据
- **排放因子**：维护来源、地域、年份、单位和版本
- **碳排放核算**：计算范围一、范围二和范围三排放
- **AI异常识别**：识别缺失、突变、重复和异常排放强度
- **减排目标**：维护基准年、目标年、路径和责任分解
- **AI减排情景**：评估节能、绿电、工艺、物流和供应链方案
- **核证管理**：管理抽样、证据、调整和独立核证
- **披露与审计**：生成盘查报告并保留方法学和数据血缘

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对AI碳核算与减排管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `EMS`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
